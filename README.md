## 📋 Project Overview

A simple, professional, and fully responsive **To-Do List App** built with **HTML, CSS, and JavaScript**. This project was created as part of my **Web Development Internship** at **SYNTECXHUB** (Task 2 — Project 1).

The app allows users to:
- ✅ Add new tasks
- ❌ Delete tasks
- ✔️ Mark tasks as complete/incomplete
- 💾 Save tasks in localStorage (data persists after page refresh)

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| **Add Task** | Type a task and click "Add" or press Enter key |
| **Delete Task** | Click the trash icon to remove a specific task |
| **Mark Complete** | Click the check icon to toggle task status |
| **localStorage** | Tasks are saved automatically — they remain after page refresh |
| **Task Counter** | Shows how many tasks are still pending |
| **Responsive** | Works on desktop, tablet, and mobile |
| **Clean UI** | Modern purple + cyan color scheme with hover effects |

---

## 🛠️ Technologies Used

- **HTML5** — Semantic structure
- **CSS3** — Flexbox, Grid, Media Queries, Transitions
- **JavaScript (Vanilla ES6)** — CRUD operations, DOM manipulation, localStorage
- **Font Awesome** — Icons for actions
- **Google Fonts** — Clean typography
